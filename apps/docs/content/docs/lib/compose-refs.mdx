title: compose refs
description: Merge multiple refs into one — callback refs, ref objects and React 19 cleanups included.
---

## Usage

```tsx
import { composeRefs, useComposedRefs } from "rockin/lib"

export function RefForwarder({ innerRef }: { innerRef?: React.Ref<HTMLDivElement> }) {
  const localRef = useRef<HTMLDivElement>(null)
  const ref = useComposedRefs(localRef, innerRef)

  return <div ref={ref} />
}
```

Two flavors:

- `composeRefs(...refs)` — returns a fresh callback ref each render
- `useComposedRefs(...refs)` — memoized version, safe to pass to DOM elements without re-attaching

Both accept callback refs, `RefObject`s and React 19 cleanup-returning callbacks.
