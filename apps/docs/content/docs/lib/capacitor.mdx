---
title: Capacitor helpers
description: Typed access to the native Capacitor runtime — with graceful web fallbacks.
---

`rockin/lib` wraps the global `window.Capacitor` runtime with typed getters and action helpers. Everything returns safe fallbacks on web, so call sites never need `if (isNative)` guards to avoid crashes.

## Usage

```tsx
import { isNativeApp, shareNativeOrWeb, pickNativeImageFiles } from "rockin/lib"

export async function SharePhoto(dataUrl: string) {
  await shareNativeOrWeb({ files: [dataUrl], title: "Check this out" })
}

export async function OnPickAvatar() {
  const files = await pickNativeImageFiles({ multiple: false })
  if (!files) return // cancelled or plugin missing
  console.log(files[0])
}
```

## What's inside

### Detection

- `isNativeApp()` — true inside a Capacitor shell
- `getNativePlatform()` — `ios` / `android` / `web`

### Plugin getters

`getNativeAppPlugin`, `getNativeStatusBarPlugin`, `getNativeBrowserPlugin`, `getNativeSharePlugin`, `getNativeCameraPlugin`, `getNativeImagePickerPlugin`, `getNativeShareFilePlugin`, `getNativeThemePlugin`, `getNativePaymentPlugin`, `getNativeShareTargetPlugin`, `getNativeAppSettingsPlugin`, `getNativeInAppUpdatePlugin` — each returns the typed plugin or `null` on web.

### Actions

- `openNativeAppSettings()`, `openExternalUrl(url, opts)`, `openUpiPaymentUrl(url, opts)`
- `shareNativeOrWeb(data, opts)` — native share sheet with `navigator.share` fallback
- `saveNativeShareImage(dataUrl, opts)`
- `pickNativeImageFiles({ multiple, limit, quality, prefix })`, `pickNativeChooserImageFiles({ limit, title })`
- `nativeSharedFileToFile()` — convert a shared file payload to a `File`

### Types

`NativeSharedFile`, `NativeSharePayload`, `NativeUpdateState`, `NativeUpdateInfo`
