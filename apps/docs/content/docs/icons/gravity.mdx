---
title: Gravity Icons
description: The Gravity UI icon set under one import.
---

`rockin/gravity` re-exports every icon from [@gravity-ui/icons](https://github.com/gravity-ui/icons):

```tsx
import { AirplaneTakeOffIcon, MagnifierIcon } from "rockin/gravity"

export function Example() {
  return <AirplaneTakeOffIcon width={16} height={16} />
}
```

Gravity icons use explicit `width`/`height` props (they default to 24px) rather than font-size. Inside rockin components, lucide is the primary icon set — Gravity icons appear in Select check indicators and a few internal pieces.
