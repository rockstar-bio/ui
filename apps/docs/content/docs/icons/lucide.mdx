---
title: Lucide Icons
description: The complete lucide-react icon set, re-exported.
---

`rockin/lucide` re-exports every icon from [lucide-react](https://lucide.dev), so projects that only import `rockin` still get the full set:

```tsx
import { Search, Settings, User } from "rockin/lucide"

export function Example() {
  return <Search className="size-4" />
}
```

Notes:

- Icons inherit `currentColor` and size via the `size-4` class (components auto-size their own icons).
- Brand icons were removed upstream in newer lucide versions — use a custom SVG for those.
- Because this is a full re-export, tree-shaking keeps bundles lean; import only what you use.

Most component docs in this library use lucide icons in their examples.
