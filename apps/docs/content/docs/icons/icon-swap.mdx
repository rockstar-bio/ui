---
title: Icon Swap
description: Crossfade + blur two icons based on a boolean state.
---

<ComponentPreview name="icon-swap" />

## Usage

```tsx
import { X, Search } from "lucide-react"
import { IconSwap } from "rockin/icon"

export function Example() {
  const [active, setActive] = useState(false)
  return (
    <IconSwap active={active} first={<Search />} second={<X />} />
  )
}
```

## API Reference

<PropsTable
  props={[
    { name: "active", type: "boolean", description: "Toggles between the two icons (drives data-state)." },
    { name: "first", type: "ReactNode", description: "Icon shown when inactive." },
    { name: "second", type: "ReactNode", description: "Icon shown when active." },
  ]}
/>

The swap animation is CSS-driven (`.t-icon-swap` classes in `rockin/styles.css`), using the shared `--icon-swap-*` tokens for duration, blur and scale. Icons render `aria-hidden`.
