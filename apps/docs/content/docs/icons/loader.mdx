## Usage

```tsx
import { Loader } from "rockin/icon"

export function Example() {
  return <Loader size={24} />
}
```

## API Reference

<PropsTable
  props={[
    { name: "size", type: "number", default: "16", description: "Spinner size in px (applied via --spinner-size)." },
    { name: "color", type: "string", default: '"currentColor"', description: "Bar color (applied via --spinner-color)." },
  ]}
/>

Requires the styles from `rockin/styles.css` (`.loader-wrapper` / `.loader-spinner` / `.loader-bar`). Pair it with a Button's `destructive`/loading state or standalone — it inherits `currentColor` when `color` is omitted.
