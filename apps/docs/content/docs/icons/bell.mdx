title: Bell Icon

<ComponentPreview name="bell-icon" />

## Usage

```tsx
import { BellIcon } from "rockin/icon"

export function Example() {
  return <BellIcon size={24} duration={1} />
}
```

## API Reference

<PropsTable
  props={[
    { name: "size", type: "number", default: "24", description: "Icon size in px." },
    { name: "duration", type: "number", default: "1", description: "Scales the ring animation speed (lower = faster)." },
    { name: "isAnimated", type: "boolean", default: "true", description: "Play the ring swing on hover." },
    { name: "color", type: "string", description: "Overrides currentColor." },
  ]}
/>

`BellIconHandle` exposes `startAnimation()` / `stopAnimation()` via ref when you need imperative control (e.g. ping on a new websocket event). Respects `prefers-reduced-motion`.
