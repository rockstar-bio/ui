title: Theming
description: Design tokens, dark mode, and brand colors — every theme is just CSS variables.
---

Every component reads design tokens from CSS variables. There is no theme object in JavaScript and no Tailwind config to extend — override the variables and the whole library follows.

## How tokens work

The stylesheet maps CSS variables into Tailwind v4 utilities with `@theme inline`:

```css
:root {
  --primary: oklch(0.205 0 0);
  --primary-foreground: oklch(0.985 0 0);
  --radius: 0.625rem;
}

@theme inline {
  --color-primary: var(--primary);
  --radius-lg: var(--radius);
}
```

That mapping is why `bg-primary`, `text-primary-foreground`, `rounded-lg` etc. all resolve to your variables. The full list of tokens lives in [`packages/ui/src/styles/globals.css`](https://github.com/rockstar-bio/ui/blob/main/packages/ui/src/styles/globals.css).

### Core tokens

| Token | Used by |
| --- | --- |
| `--background` / `--foreground` | Page canvas and default text |
| `--card` / `--card-foreground` | Card, Item, Empty surfaces |
| `--popover` / `--popover-foreground` | Popover, Select, DropdownMenu |
| `--primary` / `--primary-foreground` | Button, Badge, Switch, accents |
| `--secondary`, `--muted`, `--accent` | Subtle surfaces and hover states |
| `--destructive` | Error and delete affordances |
| `--success`, `--warning`, `--info` | Status feedback |
| `--border`, `--input`, `--ring` | Lines, form outlines, focus rings |
| `--brand` | The brand color (`#f4511e`) and default focus ring |
| `--radius` | The single source for every `rounded-*` step |
| `--sidebar-*` | Sidebar navigation surfaces |
| `--chart-*` | Chart palettes and grid colors |

## Dark mode

Dark mode is class-based. The stylesheet defines `@custom-variant dark (&:is(.dark *))`, so toggling `.dark` on `<html>` switches the theme. With `next-themes`:

```tsx
import { ThemeProvider } from "next-themes"

<ThemeProvider attribute="class" defaultTheme="system" enableSystem>
```

To brand the dark theme, override variables inside `.dark`:

```css
.dark {
  --background: oklch(0.145 0 0);
  --primary: oklch(0.922 0 0);
}
```

## Changing the brand color

`--brand` drives the focus ring (`--color-ring` maps to it) and any brand-marked component. Set it once:

```css
:root {
  --brand: oklch(0.646 0.222 41.116); /* orange */
}

.dark {
  --brand: oklch(0.705 0.213 47.604);
}
```

## Spacing and radius

All radii derive from `--radius` with multipliers, so one change re-scales every corner in the library:

```css
--radius-sm: calc(var(--radius) * 0.6);
--radius-md: calc(var(--radius) * 0.8);
--radius-lg: var(--radius);
--radius-xl: calc(var(--radius) * 1.4);
```

## Motion tokens

Shared easings and springs keep animation consistent across components (Drawer, OTP, Dock, toasts):

```css
:root {
  --ease-out: cubic-bezier(0.23, 1, 0.32, 1);
  --ease-drawer: cubic-bezier(0.32, 0.72, 0, 1);
}
```

Use them in your own CSS with `transition-timing-function: var(--ease-out)`, or import the springs from `rockin/ui/otp` (`SPRING_PRESS`, `SPRING_SWAP`, …) in your motion code.

## Accent presets

The accent is the fastest way to make rockin feel like your product. Two tokens drive it:

| Token | What it colors |
| --- | --- |
| `--brand` | Focus rings and brand marks |
| `--primary` / `--primary-foreground` | Buttons, badges, switches, selected states |

Set them once in your global CSS and every component follows, in both themes:

```css
:root {
  --brand: #3b82f6;
  --primary: #3b82f6;
  --primary-foreground: oklch(0.985 0 0);
}
```

This site ships the same presets you can try in the docs header — click a swatch to re-theme everything live:

| Preset | Color |
| --- | --- |
| Brand (default) | `#f4511e` |
| Blue | `#3b82f6` |
| Violet | `#8b5cf6` |
| Pink | `#ec4899` |
| Emerald | `#10b981` |
| Amber | `#f59e0b` |
| Cyan | `#06b6d4` |

To let users switch accents at runtime in your own app, apply the tokens on `<html>` and persist the choice:

```ts
export function setAccent(color?: string) {
  const root = document.documentElement
  if (!color) {
    root.style.removeProperty("--brand")
    root.style.removeProperty("--primary")
    root.style.removeProperty("--primary-foreground")
    return
  }
  root.style.setProperty("--brand", color)
  root.style.setProperty("--primary", color)
  root.style.setProperty("--primary-foreground", "oklch(0.985 0 0)")
}
```

The docs header picker does exactly this (plus `localStorage` persistence) — the implementation lives in `apps/docs/components/accent.tsx`.
