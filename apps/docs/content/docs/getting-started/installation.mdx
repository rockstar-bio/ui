---
title: Installation
description: Add rockin to a React 19 / Next.js project with Tailwind CSS v4.
---

rockin ships as a single package with multiple entry points. It requires **React 19**, works best with **Next.js 16**, and expects **Tailwind CSS v4** in your app.

## Install the package

```bash
# bun
bun add rockin

# pnpm
pnpm add rockin

# npm
npm install rockin
```

## Import the stylesheet

Import `rockin/styles.css` **once**, in your root layout or global CSS entry. It contains the Tailwind setup, design tokens, and all component styles.

```tsx title="app/layout.tsx"
import "rockin/styles.css"
```

That's the only CSS step — there is no `tailwind.config.js` to wire up. The stylesheet uses Tailwind CSS v4's CSS-first configuration and registers every token (colors, radii, easings, animations) as CSS variables under `:root` and `.dark`.

## Optional providers

A couple of components expect app-level providers. Mount them in your root layout once:

```tsx title="app/layout.tsx"
import { ThemeProvider } from "next-themes"
import { TooltipProvider, Toaster } from "rockin/ui"

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <ThemeProvider attribute="class" defaultTheme="system" enableSystem>
      <TooltipProvider>
        {children}
        <Toaster />
      </TooltipProvider>
    </ThemeProvider>
  )
}
```

- **`TooltipProvider`** — required for `<Tooltip />`. `delay` defaults to `0`.
- **`Toaster`** — mount once to enable `gooeyToast()` calls anywhere. Its theme follows `next-themes`.

## Native apps (Capacitor)

If the package runs inside a Capacitor shell, render `<NativeAppBridge />` at the top of your app. It syncs the status bar with your theme and wires deep links:

```tsx
import { NativeAppBridge } from "rockin/ui"

export default function RootLayout({ children }) {
  return (
    <html>
      <body>
        <NativeAppBridge />
        {children}
      </body>
    </html>
  )
}
```

## Verify it works

```tsx
import { Button } from "rockin/ui"

export default function Page() {
  return <Button onClick={() => console.log("hi")}>Hello rockin</Button>
}
```

If the button renders unstyled, double-check that `rockin/styles.css` is imported before your own global CSS and that your bundler processes CSS imports from `node_modules`.
