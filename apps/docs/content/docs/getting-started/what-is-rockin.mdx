`rockin` is the shared React UI library behind Rock Star products. It brings components, icons, hooks, and utilities into one consistent package.

It is built on accessible Base UI primitives, styled with Tailwind CSS v4, and configured through CSS variables so projects can share the same design language without a large configuration file.

## What is included

- UI components such as Button, Dialog, Input, Card, Dock, and more.
- Custom icons plus Lucide and Gravity UI icon exports.
- Hooks for media queries, mounted state, native apps, and URL state.
- Utilities for class merging, ref composition, Capacitor, and query parameters.

Browse the [components](/docs/components/button), [icons](/docs/icons/loader), and [hooks](/docs/hooks/use-media-query) to explore the library.
