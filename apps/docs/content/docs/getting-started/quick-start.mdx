---
title: Quick Start
description: Build your first rockin interface in a few minutes.
---

Start with the package stylesheet, then import the components you need from `rockin/ui`.

## Add rockin

```bash
bun add rockin
```

## Add the stylesheet

Import the stylesheet once in your root layout or global CSS entry:

```tsx title="app/layout.tsx"
import "rockin/styles.css"
```

## Render a component

```tsx
import { Button } from "rockin/ui"

export default function Page() {
  return <Button>Ship it</Button>
}
```
