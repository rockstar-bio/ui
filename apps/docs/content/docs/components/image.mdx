## Usage

```tsx
import { Image } from "rockin/ui"

export function Example() {
  return (
    <Image
      src="https://example.com/photo.jpg"
      alt="Product photo"
      width={640}
      height={360}
      wrapper="w-full rounded-xl border"
      className="h-48 w-full object-cover"
    />
  )
}
```

## Anatomy

<Anatomy importCode={'import { Image } from "rockin/ui"'} parts={["Image"]} sourcePath="ui/image.tsx" />

`src` accepts `null` — the fallback (a curious JellyMini by default, override with `fallback`) renders until an image loads successfully. `loading="eager"` implies preloading and high fetch priority.
