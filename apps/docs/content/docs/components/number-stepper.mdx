## Usage

```tsx
import { NumberStepper } from "rockin/ui"

export function Example() {
  const [seats, setSeats] = useState(4)
  return <NumberStepper label="Seats" value={seats} onChange={setSeats} min={1} max={12} />
}
```

The value is editable inline and responds to Arrow keys, Page Up/Down, Home and End. Holding either button repeats with acceleration; values are clamped to `min` and `max`. `RollingNumber` is exported separately when you need the animated value treatment in another control.
