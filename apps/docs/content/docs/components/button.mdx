## Usage

```tsx
import { Button } from "rockin/ui"

export function Example() {
  return <Button onClick={() => console.log("clicked")}>Deploy to production</Button>
}
```

<ComponentExample name="button-disabled" title='Disabled' description='Disabled buttons drop pointer events and render at 50% opacity.' />

Buttons auto-size child SVG icons and flatten their radius when nested inside a `ButtonGroup`. To render a button-styled link, pass the `render` prop: `<Button render={<a href="/pricing" />}>Pricing</Button>`.
