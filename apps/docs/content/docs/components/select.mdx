## Usage

```tsx
import { Select, SelectContent, SelectGroup, SelectItem, SelectLabel, SelectTrigger, SelectValue } from "rockin/ui"

export function Example() {
  const [value, setValue] = useState("next")
  return (
    <Select value={value} onValueChange={setValue}>
      <SelectTrigger className="w-52">
        <SelectValue placeholder="Pick a framework" />
      </SelectTrigger>
      <SelectContent>
        <SelectGroup>
          <SelectLabel>Frameworks</SelectLabel>
          <SelectItem value="next">Next.js</SelectItem>
          <SelectItem value="expo">Expo</SelectItem>
        </SelectGroup>
      </SelectContent>
    </Select>
  )
}
```

`Select` is a thin re-export of the Base UI root. `SelectContent` internally renders the portal, positioner and scroll buttons — never add your own. The popup width anchors to the trigger (min-w-36).
