## Usage

```tsx
import { Button, Dialog, DialogContent, DialogDescription, DialogFooter, DialogHeader, DialogTitle, DialogTrigger } from "rockin/ui"

export function Example() {
  return (
    <Dialog>
      <DialogTrigger render={<Button />}>Invite teammate</DialogTrigger>
      <DialogContent>
        <DialogHeader>
          <DialogTitle>Invite a teammate</DialogTitle>
          <DialogDescription>They will get an email with a magic link.</DialogDescription>
        </DialogHeader>
        <DialogFooter>
          <Button>Send invite</Button>
        </DialogFooter>
      </DialogContent>
    </Dialog>
  )
}
```

`DialogContent` renders its own portal and overlay. A close button is built in; disable it with `showCloseButton={false}`. Always include `DialogTitle` — Base UI requires it for accessibility.
