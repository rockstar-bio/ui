---
title: useMediaQuery
description: Subscribe to a CSS media query from React.
---

## Usage

```tsx
import { Badge } from "rockin/ui"
import { useMediaQuery } from "rockin/hooks"

export function ResponsiveThing() {
  const isDesktop = useMediaQuery("(min-width: 1024px)")

  return <Badge variant={isDesktop ? "default" : "outline"}>{isDesktop ? "Desktop" : "Mobile"}</Badge>
}
```

Returns `boolean`. Returns `false` during SSR and the first client render, then updates via `matchMedia` — so the server HTML always matches and hydration never mismatches.
