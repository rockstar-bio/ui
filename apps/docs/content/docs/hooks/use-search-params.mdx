title: useSearchParams
description: App-wide URL state hook on nuqs — query, filters, tabs, cart and notification flags.
---

## Usage

```tsx
"use client"

import { useSearchParams } from "rockin/hooks"

export function ProductSearch() {
  const { query, setQuery, clearQuery, category, setCategory } = useSearchParams()

  return (
    <div>
      <input
        value={query ?? ""}
        onChange={(e) => setQuery(e.target.value)}
        placeholder="Search products…"
      />
      <button onClick={clearQuery}>Reset</button>
      <p>Category: {category}</p>
    </div>
  )
}
```

## What it manages

The hook wraps [nuqs](https://nuqs.dev) `useQueryStates` with a fixed schema, so every Rock Star app shares the same URL contract:

| State | URL key | Notes |
| --- | --- | --- |
| `query` | `q` | Debounced (500ms on search screens, 800ms elsewhere) |
| `category` | `c` | Product category |
| `productStatus` | `status` | `active` / `draft` / `archived` |
| `user`, `transaction`, `transactionDetail`, `userTransaction` | `u`, `t`, `id`, `ut` | Detail views |
| `page`, `tab` | `page`, `tab` | Pagination and tabs |
| `cart`, `notification` | `cart`, `notification` | Bare flags, toggled via `replaceState` |

Each state gets `set*` / `clear*` helpers plus convenience shortcuts (`openCart`, `toggleCart`, `openNotification`, `commitQuery`, `clearAll`, `isQueryPending`, …). It also re-exports `NuqsAdapter` — mount it once at the app root.

## API Reference

Takes no arguments. Returns the state values plus the setters listed above. Updates use `history: "replace"`, `shallow: false`, `scroll: false` by default; the cart and notification flags bypass the router entirely for instant open/close animations.

For server components, use the matching parsers from `rockin/utils` (see [Lib & Utils](/docs/lib/utils)).
