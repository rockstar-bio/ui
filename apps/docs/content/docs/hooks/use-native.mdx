---
title: useNative
description: Detect when the app runs inside a Capacitor native shell.
---

## Usage

```tsx
import { Badge } from "rockin/ui"
import { useNative } from "rockin/hooks"

export function PlatformBadge() {
  const isNative = useNative()

  if (isNative === undefined) return null
  return <Badge variant={isNative ? "secondary" : "outline"}>{isNative ? "Native app" : "Web"}</Badge>
}
```

## API Reference

Takes no arguments. Returns `boolean | undefined`:

- `undefined` — before mount (SSR and first render)
- `true` — a native Capacitor runtime was detected (via `isNativeApp()` from `rockin/lib`)
- `false` — plain web

The tri-state keeps SSR output deterministic. Pair it with `NativeAppBridge` and the `rockin/lib` Capacitor helpers for plugin access.
