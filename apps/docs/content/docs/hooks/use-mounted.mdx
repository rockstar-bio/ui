title: useMounted
description: Know when your component is on the client — gate browser-only rendering safely.
---

## Usage

```tsx
import { Banner } from "rockin/ui"
import { useMounted } from "rockin/hooks"

export function ClientOnlyBanner() {
  const { mounted } = useMounted()

  if (!mounted) return null
  return <Banner>You are viewing this on a real browser.</Banner>
}
```

## API Reference

Takes no arguments. Returns `{ mounted: boolean }` — `false` on the server and first render, `true` after the component mounts.

Use it to gate anything that touches `window`, `localStorage`, or measurement APIs. For animation-heavy components that need SSR-safe sizes (like Jelly), this is the same mechanism they use internally.
