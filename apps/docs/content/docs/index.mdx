`rockin` is a private-first React component library used across every Rock Star project. It ships:

- **45+ UI components** — from primitives (Button, Input, Badge) to opinionated compositions (Dock, Jelly mascot, chat primitives, OTP flow).
- **Icons** — re-exports of [lucide](https://lucide.dev) and [Gravity UI](https://github.com/gravity-ui/icons) plus custom animated icons.
- **Hooks** — media queries, mounted state, native app detection, and URL state.
- **Utilities** — class merging, ref composition, Capacitor helpers, and query-param parsers.

Everything is built on [Base UI](https://base-ui.com) (accessible, uncontrolled-friendly primitives), styled with [Tailwind CSS v4](https://tailwindcss.com), and themed with CSS variables — no config file required.

## Package layout

Every part of the library is a separate entry point, so your bundler only pulls in what you import.

## A quick taste

```tsx
import { Button } from "rockin/ui"
import { Loader } from "rockin/icon"
import { useMounted } from "rockin/hooks"
import "rockin/styles.css"

export function Actions() {
  const mounted = useMounted().mounted
  return (
    <Button disabled={!mounted}>
      <Loader data-icon="inline-start" /> Deploy
    </Button>
  )
}
```

## Philosophy

<Steps>
  <Step>
    <h3>Own the code</h3>
    <p>rockin lives in this monorepo, versioned and released with the apps that use it. Components are plain React functions — when you need to change one, you change the source.</p>
  </Step>
  <Step>
    <h3>Accessible by default</h3>
    <p>Every interactive component wraps a Base UI primitive, so focus management, ARIA wiring, and keyboard support come for free.</p>
  </Step>
  <Step>
    <h3>Design tokens over config</h3>
    <p>Themes are CSS variables (`--background`, `--primary`, `--radius`, …). Override them in one place and every component follows.</p>
  </Step>
</Steps>
